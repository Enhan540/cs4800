How to add a Google calendar with iCal
  1. On a computer, open Google Calendar, then open Settings.
  2. Under Settings for my calendars, choose the calendar you want to add.
  3. Choose one of the iCal addresses below and copy it from Integrate calendar.
  4. Enter a calendar name above, paste the full HTTPS iCal address into the subscription URL field, and select Add Calendar.

Secret address

Your calendar can stay private. Copy Secret address in iCal format. Anyone with this link can read the feed, so keep it private and reset it in Google Calendar if it is exposed.

Google's secret address instructions

Public free/busy address

Under Access permissions for events, enable Make available to public and choose See only free/busy (hide details). Then copy Public address in iCal format. Anyone can see your busy times.

Google's public calendar instructions

Use the iCal address, not a regular Google Calendar page link. If Google returns HTTP 404, check the public sharing setting and copy the address again. If it returns HTTP 429, try again later.
